# AWS-High-Availabil-3-Tier-Application



Project Overview


AWS three tier application designed for high availability, scalability, and security.

Architecture Components
* AWS WAF
* Amazon CloudFront
* Application Load Balancer
* Nginx Web Tier
* Network Load Balancer
* Tomcat Application Tier
* Amazon RDS Multi-AZ
* Auto Scaling Groups
* VPC Flow Logs
* CloudWatch Monitoring
* IAM Roles
* S3 Log Storage

Key Features

✅ Multi-AZ deployment

✅ Private application and database subnets

✅ Centralized monitoring

✅ Security group segmentation

✅ High availability design

✅ Scalable web and application tiers
